## 🌿 hey, I'm Bhumika. but you can call me Tasha.

> *"If a VC can automate it, a VC should automate it.*
> *And if a VC can't automate it, give me a weekend."*
> — me, justifying my entire GitHub at 2am

I run a small farm. The crops are Python scripts. The cows are agents. The scarecrow is my Affinity CRM, which is mostly decorative.

By day I do **venture capital** — which, if you've ever seen it from the inside, is mostly people moving names between spreadsheets and pretending it's strategy. I'd rather talk to founders, so I wrote code to handle the rest.

The scripts don't complain. They don't ask for coffee. They don't have opinions on what's "thesis-relevant." They're the best teammates I've ever had.
